WorkBuddy 全自动免费领积分｜安装说明（Mac、Windows 通用）

请先根据自己的情况，选择下面一种安装方式。
不需要自己判断电脑是 Mac 还是 Windows，WorkBuddy 会先识别系统，再使用对应的安装程序。

安装前请确认：
1. 电脑已经安装并登录 WorkBuddy。
2. 默认每天 06:05 自动领取；需要其他时间，可以在发给 WorkBuddy 的话里改成你想要的时间。
3. ZIP 本地安装不需要访问 GitHub，但电脑必须已经有 Python 3。
4. ZIP 本地安装解决的是“不能访问 GitHub”，不是“电脑完全断网”。完全断网时 WorkBuddy 的 AI 可能无法执行安装，每日领取也无法连接腾讯服务。

==================================================
一、能访问 GitHub：复制下面这段话给 WorkBuddy
==================================================

========== 复制开始 ==========

请访问并下载这个公开、免费的开源项目：
https://github.com/liubinne/workbuddy-free-credits

请先检测我当前使用的是 macOS 还是 Windows，再完整阅读仓库中的 README.md、SKILL.md 和安装说明。在我当前这台电脑上安装“WorkBuddy 全自动免费领积分”，只操作我当前登录的 WorkBuddy 账号，默认每天 06:05 自动领取积分。

安装前先检查 Python 3、WorkBuddy 登录状态和已有签到任务；先执行 dry-run。发现旧签到任务时先备份，再安装一个新的定时任务并立即验证。不要在聊天、命令输出或日志中显示、复制、上传我的 Token、Cookie 或登录文件内容，也不要让我手工提供 Token。

如果无法访问或下载 GitHub，请停止在线安装并明确告诉我，让我改用 ZIP 本地安装；不要猜测或临时重写代码。

========== 复制结束 ==========

==================================================
二、不能访问 GitHub，或者使用别人发来的 ZIP：本地安装
==================================================

先完成这三步：
1. 把收到的 ZIP 保存到电脑并解压。
2. 在 WorkBuddy 中选择“打开文件夹”，打开解压后的 workbuddy-auto-checkin 文件夹。
3. 确认当前 WorkBuddy 已经打开这个文件夹，然后复制下面这段话给 WorkBuddy。

========== 复制开始 ==========

我已经用 WorkBuddy 打开了本地的 workbuddy-auto-checkin 文件夹。请不要访问 GitHub，也不要联网下载、猜测或重写项目文件，只使用当前文件夹里已经提供的本地文件完成安装。

请先检测我当前使用的是 macOS 还是 Windows，再完整阅读当前文件夹中的 README.md、SKILL.md 和安装说明。在我当前这台电脑上安装“WorkBuddy 全自动免费领积分”，只操作我当前登录的 WorkBuddy 账号，默认每天 06:05 自动领取积分。

安装前先检查 Python 3、WorkBuddy 登录状态和已有签到任务；先执行 dry-run。发现旧签到任务时先备份，再使用当前文件夹中的脚本安装一个新的定时任务并立即验证。不要在聊天、命令输出或日志中显示、复制、上传我的 Token、Cookie 或登录文件内容，也不要让我手工提供 Token。

如果电脑没有 Python 3，或者当前本地文件不完整，请停止安装并明确告诉我缺少什么，不要从 GitHub 下载替代文件。

========== 复制结束 ==========

不用 AI 也可以双击本地安装：
- Mac：双击 install-macos.command
- Windows：双击 install-windows.cmd
